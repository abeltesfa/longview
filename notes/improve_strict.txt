Diagnosis: The agent found the true driver (distribution loss) and became confident quickly, but it also opened beliefs testing units, a symptom 
metric, and created duplicate beliefs on the same region and metric. A wrong 'units' belief stayed active at 0.99, and two duplicate distribution 
beliefs were left active. This cost points on non-causal beliefs, duplicates, and wrong active beliefs.
  • added rule: Only propose hypotheses about causal drivers (price, distribution, promotion). Revenue and units are symptoms of those drivers, so 
never test them as the cause. (Removes the symptom-metric beliefs that cost points.)
  • added rule: Before proposing a hypothesis, check whether an active belief in the same region already tests that metric. If so, reinforce, edit, or
supersede it instead of creating a new one. (Prevents duplicate beliefs on the same region and metric.)
  • added rule: When a metric moves sharply (such as distribution falling by more than 10% in a week) and units fall with it, treat that metric as a 
leading candidate cause, and check it first each week. (Speeds up identification of the true driver.)
  • added rule: When a new belief supersedes an old one, the old one must be closed. Do not leave two active beliefs that make the same claim. (Keeps 
only one active belief per cause.)
  • added rule: A hypothesis that explains only part of a decline is not fully confirmed. Reinforce it only when its metric changes at the same time 
as the decline, and contradict it when the decline continues while its metric is flat. (Avoids over-reinforcing lagging or secondary explanations.)
  • guardrail causal_metrics_only: off → on (Blocks beliefs testing units or revenue, which are symptoms.)
  • guardrail no_duplicate_metric_beliefs: off → on (Blocks duplicate beliefs on the same region and metric.)
  • parameter reinforce_boost: 0.15 → 0.2 (Reaches the 0.7 confidence threshold faster when evidence supports the cause.)
  • parameter drop_threshold: 0.05 → 0.04 (Flag declines slightly earlier to improve timeliness.)
