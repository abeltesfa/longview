Diagnosis: The run found the true driver (price) and ended with no wrong active beliefs, but lost timeliness points. The agent spent weeks 2-3 reinforcing a 
distribution belief to 0.9 because it moved with the first drop, and only created the price belief in week 4 after distribution recovered. It also did not test 
price in week 3 when price rose, because the no-duplicate guard and the early belief focus let the first plausible lever absorb attention.
  • added rule: Each week, check every causal lever for movement, not only the one already believed. When a different lever changes during an ongoing decline, 
create a hypothesis on it immediately instead of waiting for the current explanation to fail. (Price rose in week 3 but was only tested in week 4, costing 
timeliness.)
  • added rule: A single lever can explain only the part of the decline that it coincides with. If the decline continues or deepens after that lever stabilizes 
or recovers, treat the lever as incomplete and look for another that moved later, rather than reinforcing further. (Distribution was reinforced to 0.9 even 
though revenue kept falling after the lever stopped moving.)
  • edited rule: Judge a causal belief by whether its lever changed before or at the same time as the decline began, and whether the size and direction of the 
change is consistent with the size of the decline. A lever that stayed flat or moved the wrong way cannot be the cause. (Adds direction check; helps reject 
wrong levers faster.)
  • parameter reinforce_boost: 0.2 → 0.15 (Slower escalation keeps partially-explanatory beliefs from reaching high confidence prematurely.)
  • parameter drop_threshold: 0.05 → 0.04 (Flag declines slightly earlier to improve timeliness.)
